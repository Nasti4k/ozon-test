# Тестовое задание: самый высокий супергерой

Перейдите в корень проекта
Создайте виртуальное окружение:

```powershell
python -m venv env
```

Активируйте его:

```powershell
env\Scripts\activate
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

Запуск тестов (из корня проекта):

```powershell
python -m pytest -v
```
